# OpenAI 协作任务兼容处理：灰度与回退

本功能组合了新协作任务明文适配和旧代理密文错误后的有损恢复。默认全部关闭；发布 Tag 或升级应用本身不会自动为用户启用。真实 Codex Desktop 的端到端验收仍待完成，启用前须按下文进行灰度验证。

## 管理入口与范围

在管理端「系统设置 → 网关服务 → 协作任务兼容处理」配置，使用该区域的「保存协作配置」独立保存。页面底部的「保存设置」不提交这里的草稿。

| 字段 / 界面开关 | 行为 |
| --- | --- |
| `enabled` / 启用兼容处理 | 总开关；关闭后停止新增明文生成适配、旧密文预删和恢复重试。 |
| `plaintext_enabled` / 新协作任务明文适配 | 在允许范围内适配协作工具与完整任务正文，恢复客户端所需的工具身份。 |
| `legacy_cipher_recovery_enabled` / 旧代理密文有损恢复 | 匹配可恢复加密错误且满足安全重放条件时，省略选中代理密文并最多重试一次；确认响应完成后可记住同一分支的具体省略项。 |
| `group_ids` / 启用分组 | 必须显式选择分组；空列表不启用。界面提供 OpenAI 和混合分组，网关只对支持的 OpenAI Responses 路径执行适配。 |
| `api_key_ids` / 限定 API key ID | 填写数字 ID，不填写密钥。空列表表示所选分组全部 key；非空时按「所选分组与这些 key ID 的交集」生效。 |

未配置分组、未匹配 key 或其他上游协议不启用新转换。跨账号、跨组故障转移共享同一请求的发送预算；切组重新检查策略，并隔离工具别名、明文证明和历史省略记录。

## 建议的灰度顺序

1. 保持总开关关闭，选择一个测试分组并填写测试 key 的数字 ID。
2. 先只开启「新协作任务明文适配」和总开关，保存后在测试客户端重新建立连接。
3. 用不涉及真实业务的合成任务验证 `spawn_agent`、`followup_task`、`send_message` 的完整正文、父子回信及分支隔离；校验信息只放在任务正文内。
4. 在同一范围开启「旧代理密文有损恢复」，验证旧密文与完整新任务混合历史、第二次请求失败即停止、流式内容不重复及后续轮次的具体省略项命中。
5. 核对真实 Desktop、HTTP/JSON、SSE、透传和 WS 桥接路径后，再逐组扩大范围。观察加密失败率、缺失正文反馈、延迟和额外上游用量。

有损恢复只修改发往上游的请求副本，不删除客户端旧会话或运行中的子代理。旧任务正文、结果或约束可能缺失，响应会保留网关缺失说明；依赖这些内容时需要补发完整明文。恢复响应不代表原任务完成，也不能保证所有旧会话的所有错误均消失。

## 紧急回退

点击本区域「关闭兼容处理」。该按钮使用最后一次确认保存的配置关闭总开关，未保存的草稿或分组列表加载失败不妨碍关闭。操作后以服务器返回的「已保存状态：关闭」为准；保存失败时不能视为已经关闭。

当前节点在配置成功保存后更新缓存；其他节点通过最长 2 秒的配置缓存和最长 1 秒的数据库读取获知变更，正常情况下约 2 秒，最迟还需等待有界读取完成。读取失败或配置无效时按关闭处理。开关无需重启服务，但不会强制中断已经执行的请求；新增恢复发送前还会核对当前策略。

回退时保留分组和 key 范围，仅关闭总开关。已启用会话中已经产生的明文历史仍保留必要的接收解析和回程兼容；关闭开关不会把这些历史自动变回原生密文，也无法找回此前省略的正文。不要直接降级到完全不认识明文历史的旧二进制。

已通过 HTTP 桥接建立的 WS 长连接会在后续轮次读取开关，但其传输方式不会在连接中途切回原生 WS。关闭后的新连接恢复通常的传输选择；配置范围内的原生 WS 和原生透传在每轮都保留纯明文 `agent_message` 的接收兼容，因此后续才到达的明文任务也能读取。这层兼容不会创建新工具别名、改写历史工具调用或删除密文。需要重新选择传输时，先结束当前轮次再重新连接。启用前已存在的原生 WS 连接也应重新连接后再验收新功能。

## 缓存边界与发布检查

恢复前最多暂存 2 秒、256 KiB 的流式前导内容。已出现正文、推理或工具事件时不透明重放；HTTP 200 失败且请求声明了托管工具或未知工具类型时也不自动恢复，以免重复外部动作。认证错误、限流和内容政策错误不进入代理密文清理。

被替换的失败尝试与成功响应分别记账：能够确认的失败用量记录供应商成本及账号额度，不额外扣用户余额、API key 配额或订阅额度。诊断中的 `accounting` 明确区分 `recorded`、`usage_unknown`、`cost_unknown`、`record_failed`；用量缺失不能理解为免费。数据库写入失败会留下诊断状态，本功能不增加持久记账重试队列；须结合现有运维日志监控并核对供应商账单。

明文摘要、别名及成功省略记录保存在进程内，每次更新后保留 24 小时，作用域条目有容量上限。它们不在实例间共享，重启、实例切换、过期或容量不足时不能依赖命中；相同旧密文可能再次经过上游错误后的单次恢复。缓存不保存消息正文。

省略记录按认证用户、API key、分组、显式会话、分支、消息 ID 和密文摘要隔离。没有明确分支标识时不读取或登记跨请求省略记录；失败、取消或未确认完成的响应也不登记。新密文和其他分支不会因为旧记录被自动省略。
